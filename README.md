# power-bi-sales-dashboard
Interactive Power BI Sales Dashboard analyzing sales, orders, profit, customers, and product performance
📊 Power BI Sales Dashboard
📌 Project Overview

This project presents an interactive Sales Dashboard created using Microsoft Power BI.

The dashboard analyzes sales performance and provides insights into revenue, orders, profit, customers, products, and sales trends.

The objective of this project is to transform raw sales data into an interactive dashboard that can help users understand business performance and identify important sales trends.

🎯 Project Objectives
Analyze overall sales performance
Track sales and profit trends
Analyze orders and customer performance
Identify top-performing products
Compare sales across different categories and regions
Create interactive dashboards using Power BI
Present business insights in a simple and visual format

📈 Dashboard Analysis

The dashboard provides analysis of:

Sales Trend

Analysis of sales performance over time to identify growth and changes in sales.

Product Analysis

Identification of products and categories contributing to overall sales.

Customer Analysis

Analysis of customer-level sales performance.

Regional Analysis

Comparison of sales performance across different regions.

Profit Analysis

Analysis of profitability and identification of areas contributing to overall profit.
